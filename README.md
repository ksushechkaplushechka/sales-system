Цель разработки
Целью разработки является повышение эффективности процесса
продаж, обеспечение удобного доступа клиентов к информации о товарах
и услугах, упрощение оформления и отслеживания заказов, а также
снижение нагрузки на персонал за счёт автоматизации взаимодействия с
клиентами через мобильное и web-приложения.
Средства разработки
Для проектирования и разработки web-приложения, реализующего
свой функционал на платформе Spring, а также мобильного приложения,
реализующего свой функционал c использованием платформы Flutter,
были использованы программные средства. Программные средства были 
выбраны для реализации приложения по
следующим причинам: Microsoft Windows 11 предоставляет стабильную
среду разработки и удобное взаимодействие с пользователем. VS Code
является легким и мощным инструментом для разработки мобильных
приложений на Flutter, поддерживает необходимые расширения. IntelliJ
IDEA 2024.1.1 была выбрана для разработки web-приложений, потому
что она оптимизирована для работы с Java и фреймворком Spring,
предлагая мощные инструменты для автозамены кода, рефакторинга и
отладки. IDE поддерживает интеграцию с системами контроля версий и
имеет удобные функции для тестирования, что ускоряет разработку и
уменьшает количество ошибок. Firebase Realtime Database позволяет
быстро синхронизировать данные через API. Google Chrome используется
для тестирования и отладки web-приложений, предоставляя необходимые
инструменты. LDPlayer 9 — эмулятор Android, обеспечивающий удобное
тестирование мобильных приложений. Microsoft Office 2016 —
стандартный текстовый редактор для подготовки технической и
пользовательской документации. Все эти средства обеспечивают
эффективность на всех этапах разработки и тестирования приложения.
